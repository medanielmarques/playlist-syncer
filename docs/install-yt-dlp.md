# Installing yt-dlp

YouTube and the yt-dlp devs are constantly at odds, so yt-dlp is the kind of tool that needs constant updates to work in some cases.

## Installation

```bash
sudo wget https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp -O /usr/local/bin/yt-dlp
sudo chmod a+rx /usr/local/bin/yt-dlp
```

## Upgrading

For upcoming upgrades, simply run:

```bash
sudo yt-dlp -U
```
